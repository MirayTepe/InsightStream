# InsightStream – AI PDF RAG Platform

> **Detaylı dokümantasyon:** [DOCUMENTATION.md](./DOCUMENTATION.md) – Projeyi hiç bilmeyenler için eksiksiz kurulum, API referansı ve sorun giderme rehberi.

## Overview

InsightStream is a production-ready, enterprise-grade RAG (Retrieval-Augmented Generation) platform for PDF documents:

- Ingest PDFs, extract and chunk text (PyMuPDF + LangChain)
- Create and store vector embeddings in FAISS
- Orchestrate RAG queries against Google Vertex AI (Gemini 1.5 Flash / Pro)
- Stream answers to a modern web UI (Next.js / Tailwind / shadcn/ui)

At the moment:

- **Backend** has been refactored towards a clean architecture:
  - `backend/app/core` – configuration, security, database, logging
  - `backend/app/models` – SQLAlchemy models (e.g. `User`)
  - `backend/app/repositories` – repository layer (e.g. `UserRepository`)
  - `backend/app/services` – business logic (e.g. `AuthService`, RAG services skeleton)
  - `backend/app/api/v1` – FastAPI routers (health, PDF, chat)
- **Frontend** still uses the earlier Vite/React prototype; a Next.js 14 + TypeScript + Tailwind + shadcn/ui frontend will replace it in the next steps.

This README will focus on what is already in place and how to run it.

```text
    api/
      __init__.py
      v1/
        __init__.py
        health.py
        pdf_routes.py
        chat_routes.py
```

Key points:

- **Clean architecture**: `core` (infra) → `models` → `repositories` → `services` → `api`.
- **Service‑Repository pattern**: services never talk to the DB directly; they use repositories.
- **RAG‑ready**: `pdf_service`, `ai_service`, and `vector_service` prepare a pipeline for:
  - PDF text extraction + chunking
  - Dummy embeddings + FAISS index (replaceable with real Vertex AI embeddings)

### Environment configuration

Backend settings are in `app/core/config.py` and read from a `.env` file in the `backend` directory.

Minimal `.env` to get started:

```env
PROJECT_NAME=InsightStream
ENV=dev
API_V1_PREFIX=/api/v1
JWT_SECRET_KEY=CHANGE_ME
DATABASE_URL=postgresql+psycopg2://user:password@localhost:5432/insightstream
LOG_LEVEL=INFO
```

You can copy this to:

```bash
cd backend
cp ../README.env.example .env  # when example is added
```

### Install & run backend (dev)

From the workspace root:

```bash
cd backend
python -m venv .venv
.\.venv\Scripts\Activate  # Windows PowerShell

pip install --upgrade pip
pip install -r requirements.txt

# (Optional) ensure PostgreSQL is running and DATABASE_URL is correct

uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Open:

- `http://127.0.0.1:8000/docs` – automatic FastAPI docs
- `http://127.0.0.1:8000/api/v1/health` – health check

### Implemented backend endpoints (current)

- `GET /api/v1/health` – health and DB status
- `POST /api/v1/pdf/upload` – ingest a PDF, extract text, chunk, embed (dummy), store in FAISS
- `POST /api/v1/chat/ask` – simple RAG call using dummy embeddings + FAISS
- `POST /api/v1/chat/answer-audio` – TTS placeholder (returns empty audio bytes)
